# 呼叫中心岗位职责覆盖矩阵

更新时间：2026-07-25

本矩阵用于判断平台距离“覆盖规模型呼叫中心各岗位 80% 以上日常职责”的真实差距。覆盖度是基于当前可运行代码、持久化接口和跨岗位闭环的产品评估，不以静态页面数量代替业务覆盖。

## 评估口径

- **已闭环**：有真实界面、持久化状态、服务端权限、责任岗位流转和验证动作。
- **可操作**：有真实交互，但数据仍为脱敏样本或缺少完整业务生命周期。
- **仅展示**：用于表达产品方向，尚未形成可追踪业务记录。
- 百分比是当前产品成熟度估算，不作为人岗绩效评价。

## 已验证的跨岗位链路

1. AI建议 → 本人确认草案 → 本岗位执行 → 上级验收 → 关闭/退回。
2. AI预警 → 客服主管确认 → 班长执行 → 主管验证 → 经理/总监升级闭环。
3. 质检发现问题 → 发送协同单 → 班长辅导并提交证据 → 质检复检。
4. 员工请求支持 → 班长响应 → 员工确认解决/退回。
5. 培训主管发送日报 → 客服经理提醒与批示 → 培训岗收到回执。
6. HRBP识别高风险员工 → 首次沟通 → 升级经理 → 经理处理 → HRBP备案。
7. 班组晨报 → 创建员工任务单 → 班长PDCA → 主管验证。
8. 员工调班/请假 → 班长初审 → 主管确认 → HRBP备案并更新班次。
9. 主管跨班调度 → 经理审批 → 服务端校验调出班组保护线 → 更新双方覆盖。
10. 业务/质检问题 → 培训岗创建岗中专项 → 覆盖率与测试通过率达标 → 质检独立验效 → 通过关闭并通知经理 / 退回补训。
11. 招聘到位 → 开班计划 → 培训实施 → 考试通关 → 学员档案 → 能力评估；各阶段受目标门槛和证据约束。
12. 分层抽检计划 → 录音质检 → 问题证据 → 班长协同/员工申诉 → 质检复核 → 关闭或改判。
13. 申诉与同题盲评 → 质检口径校准 → 一致率达标关闭 / 未达标自动生成培训纠偏专项。
14. 典型问题或优秀录音 → 案例草稿 → 质检审核发布 → 同步培训岗和班长。
15. 编制缺口 → HRBP招聘漏斗与补员方案 → 经理审批 → 到岗目标持续复盘。
16. 培训通关达标 → 合格名单自动转HRBP → 五项入列核验 → 经理审批 → 更新人员主数据。
17. 调动/离职/劳动关系 → HRBP事实核验 → 经理决策 → HRBP执行 → 组织与人员状态生效。
18. 人员成本实际与预测 → 自动计算预算Gap → 超预算提醒经理；员工访谈 → 行动承诺 → 定期回访归档。
19. 题库补齐与发布 → 课程场次和出勤门槛 → 员工个人考试 → 班长用录音/指标验证 → 结果回传员工与培训。
20. 员工一线建议 → 培训受理/采纳/落地 → 员工收到全过程回执。
21. 入列30/60/90日 → 培训分析能力与指标Gap → 班长确认下一阶段目标 → 员工收到成长结果。
22. 主管编制区域排班计划 → 经理审核人力缺口与补位方案 → 发布至主管和班长。
23. AI话务预测 → 主管提交技能路由方案 → 服务端校验调出侧保护线 → 经理审批 → 主管执行并回填实际接通率 → 达标关闭 / 未达标返回改进。
24. 经理提交收入、成本与毛利预测 → 总监批准经营动作 / 退回重测 → 结果回传经理持续执行。
25. 经理提交合同续约材料 → 总监确定谈判边界 → 更新合同里程碑并回传经理。
26. 经营会议草稿 → 总监发布纪要 → 会后行动进入经理/主管PDCA → 总监验收；总监跨部门事项 → 目标岗位执行 → 总监关闭或退回。

## 下一阶段优先级

1. **组织与人员主数据**：项目、区域、班组、岗位、员工、技能组和汇报关系必须从统一主数据读取，替换前端代表性样本。
2. **面谈与绩效沟通**：形成班长结构化绩效沟通、行动承诺、效果复查和员工确认。
3. **排班与ACD适配**：将计划、技能路由和效果回填连接WFM、ACD、考勤和HR主数据。
4. **经营数据适配**：接入合同、预算、财务结算、客户沟通纪要和电子签署系统。
5. **专业系统集成**：接入智能组卷、在线监考、招聘渠道、电子合同、社保薪酬与人事主数据。
6. **数据库与集成**：将 JSON 单机存储迁移到事务数据库，接入话务、工单、质检、WFM、HR和薪资系统。

达到 80% 的验收要求不是“页面存在”，而是每项职责都具备责任人、输入数据、目标/差距、动作、截止时间、跨岗协同、验证结果和审计记录。
